Python Challenge #1 —Student Grade Manager
Beginner+

Build a terminal program that:
- Lets users enter student names and grades.
- Stores students using a list of dictionaries.
- Calculates the average grade using a function.
- Displays the student with the highest grade.
- Handles invalid grade inputs using try/except.
- Keeps running until the user chooses to quit.
EXAMPLE TERMINAL OUTPUT

1. Add student
2. Show students
3. Calculate average
4. Show highest grade
5. Exit

Choose: 1
Student name: Ahmed
Grade: 95
Student added successfully!
